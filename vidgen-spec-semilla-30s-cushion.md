## 4. Estilo visual base (aplicar a TODOS los prompts)

> `cinematic macro photography, hyper-detailed, volumetric light, shallow depth of field, Colombian emerald green (#0A6E3C → #00A86B) dominant palette with warm gold highlights, earth tones, 35mm film grain, soft bokeh, dramatic rim light, natural textures, photorealistic, 8K, Tierra Mädre brand aesthetic`

**Negative prompt (constante):**
> `cartoon, illustration, cgi plastic, oversaturated, text, watermark, logo, blurry, distorted, low-res, extra fingers, artificial jewelry, fake gemstone, heart-cut gemstone, heart-shaped stone`

> `heart-cut` y `heart-shaped` van al negative prompt porque esta pieza es **cushion**.

## 6. Continuidad visual entre frames

1. **Paleta constante** — verde Chivor (#0A6E3C, #00A86B), dorado (#D4A437), tierra (#2B1810), negro (#0A0A0A). Sin azules fríos ni magentas.
2. **Luz direccional por beat** — I-II cenital cálida · III lateral dorada · IV golden hour · V ámbar volumétrico · VI fade ámbar.
3. **Sujeto puente** — el último frame de cada beat comparte un elemento con el primero del siguiente (semilla → raíz → sombra→cushion → esmeralda → luz → spark).
4. **Corte correcto** — cushion, nunca corazón. Reforzar en todos los prompts de Beat III en adelante.
5. **DOF** — f/1.8–f/2.8 equivalente, foco en el sujeto principal.
6. **Grano 35mm** sutil y constante.
7. **Sin texto en imagen** — el copy vive en voice-over y caption, nunca quemado en el frame.
8. **Seed fija** en generación (ej. `--seed 20260407`) para mantener coherencia entre runs.

## 9. Pipeline de producción con vidgen

### Checklist previo

```bash
vidgen cfg get replicate_token      # debe existir
mkdir -p ./frames-semilla-30s
```

### Opción A — imágenes estáticas + interpolación (recomendada)

```bash
# 1. Generar los 30 PNGs (flux-1.1-pro o sdxl) con los prompts de §5 + estilo base §4
#    Guardar como frame_0001.png ... frame_0030.png en ./frames-semilla-30s/
#    Usar seed fija (ej. --seed 20260407) para coherencia entre runs

# 2. Ensamblar a 1 fps
vidgen frames assemble ./frames-semilla-30s/ \
  -o semilla-30s-base.mp4 \
  --fps 1

# 3. Interpolar a 24 fps con motion smoothing
vidgen transform semilla-30s-base.mp4 \
  -o semilla-30s-24fps.mp4 \
  --filter "minterpolate=fps=24:mi_mode=mci:mc_mode=aobmc:vsbmf=1"

# 4. Grano cinematográfico + vignette
vidgen transform semilla-30s-24fps.mp4 \
  -o semilla-30s-final.mp4 \
  --effect vignette
```

### Opción B — animar cada frame como mini-clip de 1 s

Presets sugeridos por beat:

- Beat I (01–05) → `zoom-in` (acercamiento íntimo)
- Beat II (06–10) → `zoom-out` (de la raíz al árbol a la comunidad)
- Beat III (11–15) → `orbit` (revelación del cushion)
- Beat IV (16–20) → `pan-left` (del tesoro al cuerpo)
- Beat V (21–25) → `pan-up` (del suelo al poste encendido)
- Beat VI (26–30) → `zoom-out` (apertura emocional final)

```bash
for i in $(seq -w 1 30); do
  vidgen animate frame_00${i}.png \
    -o clip_00${i}.mp4 \
    --motion <preset-por-beat>
done

# Concatenar
ffmpeg -f concat -safe 0 -i clips-list.txt -c copy semilla-30s-animated.mp4
```

### Opción C — híbrida (máximo impacto / costo razonable)

Beat III (revelación del cushion) y Beat V (poste que se enciende) como clips animados con `vidgen animate`. El resto como imágenes estáticas interpoladas. Mejor balance costo-impacto.
