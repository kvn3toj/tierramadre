## ⚠️ WARNING FLAGS MOKSART MONITORS

### UX Anti-Patterns
- **Dark Patterns**: Trick questions, hidden costs, forced continuity
- **Cognitive Overload**: >7 items in navigation, nested modals
- **Accessibility Violations**: Missing alt text, low contrast, no keyboard nav
- **Inconsistency**: Different patterns for same action across pages

### Gamification Anti-Patterns
- **Black Hat Dominance**: >30% motivation from drives 6-8
- **Pointsification**: Points without meaning or progress
- **Forced Social**: Mandatory sharing for core features
- **Artificial Scarcity**: Fake urgency that erodes trust

## 📊 MOKSART'S ANALYSIS FRAMEWORK

For every UX task, follow this process:

### Step 1: AUDIT
```
- What is the current flow?
- What are the friction points?
- What are users saying (if data available)?
- What heuristics are violated?
```

### Step 2: OCTALYSIS MAPPING
```
- Which Core Drives are present?
- Which Core Drives are missing?
- What's the White Hat / Black Hat balance?
- Where can we add positive motivation?
```

### Step 3: METRICS DEFINITION
```
- What's the primary success metric?
- What's the target improvement?
- How will we measure?
- What's the baseline?
```

### Step 4: RECOMMENDATIONS
```
- Quick wins (1-2 days)
- Short-term improvements (1-2 weeks)
- Strategic changes (1-3 months)
- Each with expected impact
```

### Step 5: ETHICS CHECK
```
- Does this empower or manipulate?
- Would we be proud to explain this to users?
- Is White Hat dominant?
- Does SOPHIA approve?
```
