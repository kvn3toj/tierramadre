Setup paso a paso

Configuración inicial

1Crear cuenta GHL Pro

  • Ir a gohighlevel.com y registrarse con Pro Plan ($297/mes)
  • Verificar email + completar perfil de la empresa
  • Crear sub-account "Tierra Madre" en el menú Agency
  • Configurar timezone: America/Bogota
  • Configurar moneda: COP
  • Subir logo + paleta de colores de la marca

2Verificar WhatsApp Business API

  • Settings → Phone Numbers → Add WhatsApp
  • Conectar Meta Business Manager (Facebook account)
  • Verificar negocio en Meta: subir documentos legales
  • Comprar/asignar número LC Phone (~$2/mes) o usar Twilio
  • Solicitar verificación de WhatsApp (24-48h)
  • Una vez aprobado: registrar plantillas iniciales en Meta Business

3Conectar Instagram Business + TikTok

  • Instagram: Settings → Integrations → Facebook/Instagram → Login con Meta Business → autorizar cuenta IG Business de Tierra Madre
  • TikTok: Settings → Integrations → TikTok → autorizar TikTok for Business
  • Verificar que DMs entran al inbox unificado de GHL
  • Configurar auto-respuesta inicial mientras la IA no está activa

4Generar Private Integration Token

  • Settings → Integrations → Private Integrations
  • Click "Create Token"
  • Permisos a otorgar: contacts (read+write), conversations (read+write), workflows (trigger), opportunities (read+write), custom-fields (read), calendars (read+write)
  • Copiar token (solo se ve 1 vez) → guardar en password manager
  • Entregar token a Área 2 (Supabase) y Área 4 (Cloudflare Workers)

Pipeline

7 Etapas del embudo de ventas

Crear en Opportunities → Pipelines → Add Pipeline "Ventas Tierra Madre" con estas etapas en orden:

1. Nuevo Lead — Entra por cualquier canal · primer mensaje
2. Calificado por IA — Presupuesto + interés capturados
3. Producto Recomendado — IA envió 1-3 opciones del catálogo
4. Carrito Enviado — Link de checkout entregado
5. Negociación / Agente — Requiere atención humana
6. ✅ Venta Cerrada — Pago confirmado por Mercado Pago
7. ❌ Perdido / Nurturing — No compró — entra a campaña re-engagement

Automatizaciones

Los 13 Workflows a construir

En Automation → Workflows → Create Workflow. Cada uno con su trigger y acciones específicas.

WF-01

Nuevo contacto multi-canal

Trigger: "Contact Created" OR "Inbound Message"

Acciones:

  • Verificar si contacto existe (por celular/IG/email)
  • Si NO: crear contacto, asignar tag canal-{wa/ig/tt}
  • Trigger workflow WF-02 (verificar embajador)
  • Enviar plantilla WA-01/IG-01/TT-01 según canal
  • Mover a etapa "Nuevo Lead"
WF-02

Verificar embajador

Trigger: Llamado por WF-01

Acciones:

  • POST a Supabase Edge Function /match-ambassador
  • Si match: update embajador_asignado
  • Enviar EM-01 al embajador por WA
  • Pausar IA 5 minutos (sleep)
  • Si embajador no responde: continuar con WF-03
WF-03

Calificación con IA

Trigger: Llamado por WF-01 (sin embajador)

Acciones:

  • Activar Conversation AI con el "Sales Bot"
  • IA hace 4 preguntas: tipo, presupuesto, ocasión, conocimiento
  • Cada respuesta actualiza custom field correspondiente
  • Trigger WF-04 al completar calificación
  • Mover a etapa "Calificado por IA"
WF-04

Búsqueda en catálogo

Trigger: Custom event "qualification_complete"

Acciones:

  • POST a Supabase Edge Function /search-products
  • Recibir 3 productos en JSON
  • IA arma mensaje con fotos + precios + links
  • Enviar por canal del contacto
  • Mover a etapa "Producto Recomendado"
WF-05

Envío de carrito + checkout

Trigger: Keyword "lo quiero" OR "cómo pago"

Acciones:

  • POST a /create-order en Supabase
  • Recibir URL de Mercado Pago
  • Enviar plantilla CK-01 con el link
  • Mover a etapa "Carrito Enviado"
WF-06

Escalación a agente

Trigger: Keyword "hablar con alguien" OR sentimiento negativo

Acciones:

  • Trigger WF-11 (smart routing)
  • Pausar IA en este contacto
  • Enviar plantilla ES-01
  • Notificar al agente asignado por SMS + email
  • Mover a etapa "Negociación / Agente"
WF-07

Regla 5 min embajador

Trigger: Sleep timer en WF-02

Acciones:

  • Verificar si embajador respondió
  • Si NO: activar IA, continuar conversación
  • Conservar embajador_asignado (comisión protegida)
  • Notificar al embajador "IA tomó tu lead, igual ganas comisión"
WF-08

Post-venta

Trigger: Webhook MP "payment.approved"

Acciones:

  • Update total_comprado_cop y ultima_compra_fecha
  • Mover a "Venta Cerrada"
  • Enviar plantilla CK-03 (confirmación)
  • Agendar: D+1 PV-01, D+entrega PV-02, D+7 PV-03 (review)
  • Si tiene embajador: notificar EM-02 (comisión ganada)
WF-09

Re-engagement / lead frío

Trigger: Cron diario · contactos >7d sin respuesta

Acciones:

  • Restar 10 pts al score
  • Si >7d: enviar plantilla R-03
  • Si >30d: enviar R-04 con descuento
  • Si >60d sin respuesta: mover a "Perdido / Nurturing"
WF-10

Asistencia a evento

Trigger: Form submitted "Evento {nombre}"

Acciones:

  • Crear/actualizar contacto
  • Tag evento-{slug}-rsvp
  • Generar QR único
  • Agendar recordatorios: 3d, 1d, 2h
  • Post-evento: secuencia agradecimiento + oferta
WF-11

Smart Routing (agentes especializados)

Trigger: Llamado por WF-06

Acciones:

  • Aplica matriz de decisión (Base 9):
  • Embajador → embajador
  • Inversión + monto >5M → agente_inversion
  • Urgencia/queja → agente_senior
  • Score >81 → agente_premium
  • Default → agente_regular
  • Round-robin dentro del pool
WF-12

Auto-event-invite

Trigger: Custom event "event_created" (desde admin)

Acciones:

  • POST a Supabase /auto-event-invite
  • Filtra contactos por audience_filters
  • Para cada uno: envía EV-01 o EV-02 por canal_preferido
  • Tag evento-{slug}-invitado
WF-13

Ambassador Scoring (cron)

Trigger: Cron diario 00:00

Acciones:

  • POST a Supabase /calculate-ambassador-score
  • Para embajadores que cambiaron de nivel:
  • Si SUBE: plantilla EM-03 (celebración) + actualizar % comisión
  • Si BAJA: plantilla EM-04 (coaching)

API

Endpoints API v2 a usar

Base URL: https://services.leadconnectorhq.com

Headers obligatorios: Authorization: Bearer {PRIVATE_TOKEN} y Version: 2021-07-28

// CONTACTS
POST   /contacts                              → Crear contacto
GET    /contacts/{contactId}                  → Leer contacto
PUT    /contacts/{contactId}                  → Actualizar custom fields + tags
DELETE /contacts/{contactId}                  → Eliminar
POST   /contacts/{contactId}/tags             → Agregar tags
GET    /contacts/search                       → Buscar por query

// CONVERSATIONS
POST   /conversations/messages                → Enviar mensaje (WA/IG/SMS/Email)
GET    /conversations/search                  → Buscar conversaciones
GET    /conversations/{conversationId}        → Leer conversación
POST   /conversations/                        → Crear nueva

// OPPORTUNITIES (pipeline)
POST   /opportunities                         → Crear oportunidad
PUT    /opportunities/{id}                    → Mover a otra stage
GET    /opportunities/{id}                    → Leer
POST   /opportunities/search                  → Filtrar

// WORKFLOWS
POST   /workflows/{workflowId}/subscriptions  → Disparar workflow

// CUSTOM FIELDS
GET    /custom-fields                         → Listar
POST   /custom-fields                         → Crear

// CALENDARS
GET    /calendars                             → Listar calendarios
POST   /calendars/events                      → Crear evento

// FORMS
GET    /forms                                 → Listar
GET    /forms/{formId}/submissions            → Ver respuestas

// WEBHOOKS (configuración inbound)
Configurar URL de webhook en Integrations → Webhooks
Tipos a suscribirse:
- ContactCreate, ContactUpdate, ContactDelete
- InboundMessage (WA/IG/SMS)
- OpportunityCreate, OpportunityUpdate
- AppointmentScheduled
- FormSubmission
