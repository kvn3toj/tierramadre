ÁREA 1 · FRONTEND WEB

Página, landings y admin

Construir la página madre, las 6 landing pages, las páginas de producto, el carrito, el checkout y el admin interno con Vite + React + framer-motion + Tailwind. Conectado a Supabase y GoHighLevel.

Vite 5 React 19 Framer Motion 12 Tailwind CSS 4 TanStack Query 5 React Router v7 Supabase JS

Objetivo

Qué construye esta área

Toda la experiencia visible al usuario final. Un sitio web ultra rápido, con animaciones cinematográficas tipo framer-motion, que vende joyas de lujo y captura cada lead.

  • Home animada con hero, sección de productos destacados, historia de la marca
  • Catálogo madre en /catalogo con filtros (categoría, precio, ocasión)
  • Página de producto con galería 360°, certificado descargable, productos relacionados
  • 6 landing pages por categoría con formulario de pre-calificación
  • Carrito persistente (estado React + Supabase)
  • Checkout custom integrado con Mercado Pago
  • Formularios de embajadores y eventos
  • Admin interno en /admin: gestión de productos, promociones, dashboard BI
  • Portal embajador en /embajador: dashboard personal, leads, comisiones

📦 Entregables

  • Repositorio Git con código limpio y comentado
  • App Vite deployada en Vercel o Cloudflare Pages
  • Dominio configurado con SSL
  • Lighthouse score >90 en Performance, SEO, A11y
  • Conectado a Supabase (lectura/escritura)
  • Conectado a GHL via webhook/API
  • Conectado a Mercado Pago checkout
  • Build <5s, HMR instantáneo
  • Sistema de diseño documentado
  • Tests E2E básicos (carrito + checkout)

Ejecución

Paso a paso para arrancar

Sigue estos pasos en orden. Cada paso tiene su prompt de Claude Code listo para copiar.

1Crear proyecto Vite + React + TS

npm create vite@latest tierramadre-web -- --template react-ts
cd tierramadre-web
npm install

Verifica que npm run dev abre en localhost:5173

2Instalar dependencias

npm install react-router-dom @supabase/supabase-js \
  @tanstack/react-query zustand framer-motion \
  react-hook-form @hookform/resolvers zod \
  lucide-react clsx tailwind-merge \
  date-fns recharts @tanstack/react-table \
  embla-carousel-react react-dropzone

npm install -D tailwindcss@next @tailwindcss/vite \
  @types/node vitest @playwright/test \
  eslint prettier husky

3Configurar Tailwind 4 + theme de Tierra Madre

Configura Tailwind CSS 4 con Vite. Define un theme custom con: - Paleta esmeralda (50-900) basada en #10b981 - Paleta dorada (300-700) basada en #fcd34d - Fuentes: Inter (sans) y Playfair Display (serif) - Dark mode por defecto - Animaciones personalizadas: fade-up, fade-in, scale-in Crea el archivo tailwind.config.ts y actualiza src/styles/globals.css

4Conectar Supabase

Crea src/lib/supabase.ts que exporte el cliente de Supabase usando: - VITE_SUPABASE_URL (desde .env.local) - VITE_SUPABASE_ANON_KEY (desde .env.local) También crea src/lib/types.ts con los tipos TypeScript para: - Product (según schema de Base 1) - Order - Promotion - Ambassador - Event Crea .env.example con las variables necesarias documentadas.

5Setup React Query + Zustand

Configura @tanstack/react-query en src/App.tsx con un QueryClient global. Crea src/store/cartStore.ts con Zustand que maneje: - items: CartItem[] - addItem, removeItem, updateQuantity, clearCart - subtotal computed - Persistencia en localStorage Crea hook useCart() para acceder fácil.

6Construir layout base con framer-motion

Crea src/components/layout/Header.tsx con: - Logo de Tierra Madre (placeholder por ahora) - Menú: Catálogo, Topitos, Anillos, Eventos, Embajadores - Ícono de carrito con badge de cantidad (lee de cartStore) - Animaciones framer-motion: el header se desliza desde arriba al cargar - Mobile: menú hamburguesa con drawer animado Crea src/components/layout/Footer.tsx con info de contacto, redes y políticas. Crea src/components/animations/FadeIn.tsx (wrapper con variants para entrada con scroll trigger usando useInView de framer-motion).

7Página Home con secciones animadas

Crea src/pages/Home.tsx con estas secciones (cada una con animación al entrar en viewport): 1. Hero a pantalla completa con video de fondo + headline + CTA "Ver Catálogo" 2. Productos destacados (4 cards en grid, query a Supabase WHERE destacado=true) 3. Historia de la marca con paralax suave 4. Galería de eventos pasados (carrusel con embla) 5. Testimonios automáticos (Base C3 - query a tabla testimonials) 6. CTA final "Habla con un asesor" que abre WhatsApp Usa framer-motion para todas las animaciones. Mobile-first responsive.

8Catálogo con filtros

Crea src/pages/Catalog.tsx con: - Grid responsive de productos (cards animadas) - Sidebar con filtros: categoría (chips), rango de precio (slider), ocasión (checkboxes) - Búsqueda por texto (full-text en Supabase con tsvector) - Paginación o infinite scroll - Animaciones stagger al cargar productos - Usa useQuery para fetch + cache Crea src/components/product/ProductCard.tsx reutilizable con: - Foto principal (de fotos[0]) - Hover muestra segunda foto con crossfade - Precio formateado en COP - Badge si está destacado - Tap → navega a /producto/:slug con transición

9Página de producto con galería 360° (A3)

Crea src/pages/ProductPage.tsx que reciba :slug, fetch del producto. Layout: - Columna izquierda: ProductGallery360 (24 fotos giratorias) - Columna derecha: nombre, precio, descripción, selector de cantidad, botón "Agregar al carrito" - Sección bajo: certificado descargable (PDF de Supabase Storage) - Sección bajo: productos relacionados (misma categoría) Crea src/components/product/ProductGallery360.tsx usando react-360-product-viewer. Las 24 fotos están en Supabase Storage en /products/{sku}/360/01.jpg...24.jpg Botón "Agregar al carrito" anima: el producto vuela hacia el ícono del carrito (framer-motion layout animations).

10Carrito + Checkout + Mercado Pago

Crea src/components/cart/CartDrawer.tsx (slide desde la derecha animado). Crea src/pages/Checkout.tsx con formulario en pasos: 1. Datos cliente (nombre, email, celular, ciudad, dirección) 2. Resumen de orden 3. Selección método de pago (botones grandes: Tarjeta, PSE, Nequi, Daviplata) Al confirmar: 1. POST a Supabase Edge Function /create-order que devuelve order_id 2. POST a /functions/v1/mp-create-preference con order_id (devuelve URL de MP) 3. Redirige al Checkout Pro de Mercado Pago Después del pago, MP redirige a /pedido-confirmado/:order_id que muestra estado y agradecimiento.

11Landing pages × 6

Crea las 6 landing pages siguiendo el template: - src/pages/landings/Topitos.tsx - src/pages/landings/AnillosCompromiso.tsx - src/pages/landings/Dijes.tsx - src/pages/landings/GemasSueltas.tsx - src/pages/landings/Sets.tsx - src/pages/landings/Inversion.tsx Cada landing tiene: 1. Hero con imagen de la categoría + headline emocional 2. Formulario de pre-calificación (nombre, celular, presupuesto, ocasión) que envía a Supabase + dispara workflow GHL #01 3. Galería 6-9 productos top de esa categoría 4. Storytelling de la categoría 5. Reviews específicos 6. FAQ 7. CTA dual: "Hablar con asesor" (abre WA) y "Ver catálogo completo" Todas con framer-motion. Mobile-first.

12Admin Panel · gestión de productos y promos

Crea /admin con login (Supabase Auth, magic link). Rutas protegidas: - /admin → Dashboard (Base D1) con cards de métricas + gráficos Recharts - /admin/productos → tabla con TanStack Table, crear/editar/eliminar - /admin/productos/nuevo → form con: nombre, SKU, categoría, precio, keywords (tags), ocasiones (multi), upload fotos con react-dropzone, upload certificado PDF, stock, destacado/activo toggles - /admin/promociones → Base 13 completa - /admin/eventos → crear evento con filtros de audiencia + dispara workflow #12 - /admin/embajadores → tabla con score, leads, comisiones acumuladas - /admin/comisiones → tabla mensual, aprobar pagos pendientes Todo con Row Level Security en Supabase para seguridad.

13Portal Embajador

Crea /embajador con login para embajadoras. Rutas: - /embajador → Dashboard con su score, próximo nivel, leaderboard mensual - /embajador/leads → tabla de sus leads cargados, estado, pipeline - /embajador/leads/nuevo → form para cargar lead nuevo (dispara workflow #06) - /embajador/comisiones → comisiones acumuladas del mes, historial pagos - /embajador/kit → kit de marketing descargable (fotos, plantillas) Diseño con sensación premium, framer-motion animaciones suaves.

14Chat embebido de GHL

Embebe el widget de chat de GoHighLevel en el sitio. GHL provee un snippet JS que se inserta en el body. Crea src/components/chat/ChatWidget.tsx que cargue el script solo en producción (no en /admin). El widget debe: - Aparecer como burbuja flotante abajo derecha - Estilo coherente con Tierra Madre (color esmeralda) - Mobile-friendly

15Optimización + deploy

Optimiza: - Lazy load todas las rutas con React.lazy + Suspense - Image optimization: Supabase devuelve URLs con ?width=X&quality=Y - Code splitting por ruta - Preload de fuentes con Inter y Playfair - Implementa meta tags + Open Graph + JSON-LD por página (SEO) Deploy: - Crea repo en GitHub - Conecta a Vercel (o Cloudflare Pages) - Configura las env vars en el dashboard - Verifica Lighthouse: Performance >90, SEO 100, A11y >90 - Conecta dominio personalizado con SSL

Una sola plataforma desde donde el admin maneja TODO: productos, promociones, eventos, embajadores, agentes, plantillas de mensajes, dashboard, comisiones, testimonios, configuración global. Sin tener que entrar a 5 herramientas distintas.

Configurar pool por especialidad (Inversión, Senior, Regular, Premium). Asignar usuarios. Horarios. Capacidad máxima.

Pendientes de pago. Aprobar en lote. Exportar Excel. Historial completo. Notificación automática al embajador al pagar.

Las 30+ plantillas (Base 14). Editar texto. Estado de aprobación Meta. Variables disponibles. Preview antes de guardar.

📝 Contenido Landings

Editar textos de cada landing sin tocar código. CMS lite: hero, historia, FAQ. Cambios live en segundos.

/admin/personas

👤 Personas (NUEVO · crítico)

Crear/editar embajadores y agentes. Enviar invitación por correo con magic link. Onboarding automático. Todo lo que hagan queda enlazado a su perfil.

/admin/config

⚙️ Configuración Global

Horarios de atención. Mensajes por defecto. % comisiones por nivel. Reglas de scoring. Integraciones (GHL, MP, etc.).

🔐 Permisos por rol

No todos en el equipo necesitan acceso a todo. Sistema de roles con Supabase RLS:

👑 Super Admin (fundadores)

Acceso completo a los 12 módulos. Único que puede aprobar comisiones, cambiar config global, eliminar productos.

📋 Admin Operativo

Productos, promociones, eventos, testimonios, plantillas, dashboard. NO toca comisiones ni config crítica.

🎨 Marketing / Contenido

Solo: productos (crear/editar fotos+textos), contenido landings, testimonios (moderar), plantillas (editar).

💼 Ventas / Agente

Solo: dashboard (su parte), órdenes (las propias), chat (vía GHL embebido). No accede a config ni a otros agentes.

⚙️ Qué pasa al hacer click en "Crear e invitar"

Frontend (Vite)
  1. Valida form con zod schema
  2. Muestra loading state
  3. POST a Supabase Edge Function /invite-ambassador
  4. Recibe respuesta con status + slug + magic link URL
  5. Muestra toast "Invitación enviada a {email}"
  6. Redirige a /admin/personas/embajadores/{id}
  7. Lista actualizada automáticamente (Realtime)
Backend (Edge Function)
  1. Verifica que email no exista ya
  2. Genera slug único {nombre-kebab}-{4chars}
  3. INSERT en tabla ambassadors con status='invited'
  4. Crea usuario en Supabase Auth con rol 'embajador'
  5. Llama supabase.auth.admin.inviteUserByEmail()
  6. Crea carpeta Storage ambassadors/{id}/
  7. POST a GHL API: agrega tag embajador-{slug}
  8. Envía email custom con plantilla de bienvenida (Resend o GHL)
  9. Return: {id, slug, form_url, dashboard_url}

📋 Listado de embajadores · tabla con acciones

Implementar con TanStack Table. Columnas y filtros:

  • Columnas: Avatar+Nombre, Email, Nivel, Score, # Leads, Ventas $, Comisión $, Estado, Última actividad, Acciones
  • Filtros: Estado (active/invited/paused/archived), Nivel, Ciudad, Búsqueda por nombre/email
  • Ordenamiento: Por score, ventas, fecha de ingreso, última actividad
  • Acciones por fila (menú): Ver perfil, Editar, Reenviar invitación, Cambiar nivel, Pausar, Suspender, Archivar
  • Acción bulk: Seleccionar varios → pausar/reactivar/exportar CSV
  • Realtime: usa Supabase Realtime para reflejar cambios sin recargar

🚀 Prompt 1 · Inicialización del proyecto

Necesito que crees un proyecto React + Vite + TypeScript para una marca de joyería de lujo llamada "Tierra Madre" que vende esmeraldas colombianas. Stack: - Vite 5 + React 19 + TypeScript - Tailwind CSS 4 + framer-motion 12 - React Router 7 - @supabase/supabase-js + TanStack Query 5 - Zustand para estado global Arquitectura: - Frontend custom (sin Shopify) - Backend en Supabase (postgres + storage + auth) - CRM y multi-canal en GoHighLevel - Pagos con Mercado Pago Checkout API Crea la estructura de carpetas según área-1-frontend.html, inicializa el proyecto, instala deps, configura Tailwind con paleta esmeralda+dorada, fuentes Inter+Playfair, modo dark por defecto. Crea el archivo .env.example con todas las variables necesarias documentadas. Crea src/lib/supabase.ts con el cliente. Crea src/lib/types.ts con interfaces de Product, Order, Promotion, Ambassador, Event según el schema definido. Configura React Router con todas las rutas listadas en la estructura, con lazy loading. Crea componentes layout base: Header (con menú animado + carrito badge), Footer, MobileMenu. Crea componentes de animación reutilizables: FadeIn, StaggerChildren, PageTransition usando framer-motion. El sitio debe sentirse premium, oscuro elegante (negro con acentos esmeralda y dorados), animaciones suaves tipo Awwwards.
