Objetivo

Qué construye esta área

El sistema de diseño completo que Área 1 (Frontend) usará para construir todo. Esto NO es código — son tokens, componentes en Figma, guías de animación, y especificaciones técnicas que el frontend traduce a Tailwind + framer-motion.

  • Paleta de colores con tokens semánticos (50-900 por escala)
  • Tipografía: jerarquías y reglas de uso
  • Sistema de espaciado consistente
  • Componentes UI en Figma (botones, cards, inputs, modales, tabs, etc.)
  • Iconografía custom + uso de Lucide
  • Catálogo de animaciones framer-motion con código snippets
  • Guía mobile-first responsive
  • Accesibilidad WCAG AA
  • Tono visual: oscuro premium con acentos esmeralda y dorados

📦 Entregables

  • Archivo Figma "Tierra Madre Design System"
  • tailwind.config.ts con tokens custom
  • src/styles/globals.css con CSS variables
  • Documento de uso de framer-motion (variants estándar)
  • Guía de iconografía (Lucide + custom SVGs)
  • Mockups de las 6 landings + home + producto
  • Animaciones de referencia (video o Lottie)
  • Guía de fotografía de productos (estándares)

Animaciones

Catálogo framer-motion

Snippets pre-armados para que Área 1 los use directamente. Mismo timing, mismo easing, sensación coherente en todo el sitio.

⚙️ Easing y duraciones estándar

// src/lib/animations.ts
export const easings = {
  smooth: [0.22, 1, 0.36, 1],      // Default · cubic-bezier de framer-motion
  bounce: [0.68, -0.55, 0.265, 1.55],
  spring: { type: 'spring', stiffness: 200, damping: 25 },
};

export const durations = {
  fast: 0.3,    // micro-interactions, hover
  base: 0.6,    // page transitions, entrances
  slow: 1.2,    // hero, dramatic moments
};

Fade In Up

export const fadeInUp = {
  initial: { opacity: 0, y: 40 },
  animate: { opacity: 1, y: 0 },
  exit: { opacity: 0, y: -20 },
  transition: { duration: 0.6, ease: [0.22, 1, 0.36, 1] }
};

// Uso:
<motion.div {...fadeInUp}>
  Contenido
</motion.div>

Stagger Children

export const stagger = {
  animate: {
    transition: { staggerChildren: 0.1, delayChildren: 0.1 }
  }
};

// Uso:
<motion.div variants={stagger} initial="initial" animate="animate">
  {items.map(item => (
    <motion.div key={item.id} variants={fadeInUp}>
      {item.name}
    </motion.div>
  ))}
</motion.div>

Page Transition

export const pageTransition = {
  initial: { opacity: 0, y: 20 },
  animate: { opacity: 1, y: 0 },
  exit: { opacity: 0, y: -20 },
  transition: { duration: 0.4, ease: 'easeInOut' }
};

// En App.tsx con AnimatePresence:
<AnimatePresence mode="wait">
  <motion.div key={location.pathname} {...pageTransition}>
    {children}
  </motion.div>
</AnimatePresence>

Scroll Reveal (with viewport)

// Wrapper component
function FadeOnView({ children, delay = 0 }) {
  return (
    <motion.div
      initial={{ opacity: 0, y: 40 }}
      whileInView={{ opacity: 1, y: 0 }}
      viewport={{ once: true, margin: '-50px' }}
      transition={{ duration: 0.7, delay, ease: [0.22,1,0.36,1] }}
    >
      {children}
    </motion.div>
  );
}

Mobile-first

Responsive y accesibilidad

📱 Breakpoints (Tailwind)

screens: {
  'sm': '640px',   // móvil grande
  'md': '768px',   // tablet
  'lg': '1024px',  // laptop
  'xl': '1280px',  // desktop
  '2xl': '1536px', // pantalla grande
}

// Filosofía mobile-first:
<div class="text-sm md:text-base lg:text-lg">
  // 14px → 16px → 18px progresivo
</div>

♿ Accesibilidad WCAG AA

  • Contraste mínimo 4.5:1 para texto normal
  • Contraste 3:1 para texto grande y UI
  • Focus visible en todos los elementos interactivos
  • Alt text en todas las imágenes
  • aria-labels en iconos sin texto
  • Navegación 100% por teclado
  • Tap targets mínimo 44x44px en mobile
  • Respeta prefers-reduced-motion

📏 Espaciado consistente (8pt grid)
