## 6. Continuidad visual entre frames

**Reglas duras para mantener coherencia:**

1. **Paleta constante** — verde Chivor (#0A6E3C, #00A86B), dorado cálido (#D4A437), tierra húmeda (#2B1810), negro profundo (#0A0A0A). No introducir azules fríos ni magentas.
2. **Luz direccional** — acto I-II: luz cenital cálida. Acto III: luz lateral dorada. Acto IV: azul-violeta crepuscular. Acto V-VI: ámbar cálido volumétrico.
3. **Sujeto puente** — en cada transición de acto, el último frame del acto anterior debe compartir un elemento visual con el primero del siguiente (semilla → raíz → cristal → esmeralda → luz → comunidad).
4. **Profundidad de campo** — siempre f/1.8–f/2.8 equivalente, foco en el sujeto principal.
5. **Grano de película** — 35mm grain sutil y constante en todos los frames.
6. **Sin texto en imagen** — el copy va como voice-over / caption, nunca incrustado en el frame.

## 7. Pipeline de producción con vidgen

### Opción A — 60 imágenes estáticas vía Replicate + ensamble

```bash
# 1. Verificar token Replicate
vidgen cfg get replicate_token

# 2. Generar cada frame (ejemplo frame 01)
#    NOTA: vidgen generate produce video, no imágenes estáticas.
#    Para imágenes puras conviene usar Replicate directamente (flux, sdxl).
#    Este spec asume que generarás cada PNG con tu modelo preferido
#    usando los prompts de la tabla §5 + el estilo base §4.

# 3. Colocar los 60 PNGs en ./frames-semilla/ nombrados frame_0001.png ... frame_0060.png

# 4. Ensamblar a video (1 frame por segundo → interpolar a 24 fps suavemente)
vidgen frames assemble ./frames-semilla/ \
  -o semilla-base.mp4 \
  --fps 1

# 5. Interpolar a 24 fps con motion smoothing (ffmpeg filter)
vidgen transform semilla-base.mp4 \
  -o semilla-24fps.mp4 \
  --filter "minterpolate=fps=24:mi_mode=mci:mc_mode=aobmc:vsbmf=1"

# 6. Aplicar grano cinematográfico y vignette
vidgen transform semilla-24fps.mp4 \
  -o semilla-final.mp4 \
  --effect vignette
```

### Opción B — Animar cada frame como mini-clip y concatenar

Para mayor fluidez, cada frame puede convertirse en un clip de 1 segundo con `vidgen animate` (motion sutil):

```bash
vidgen animate frame_0001.png \
  -o clip_0001.mp4 \
  --prompt "gentle dew-drop settle, slow push-in" \
  --motion zoom-in

# Repetir para los 60 frames con presets variados por acto:
# Acto I-II: zoom-in
# Acto III:  orbit
# Acto IV:   pan-left
# Acto V:    zoom-out
# Acto VI:   pan-up

# Concatenar con ffmpeg
ffmpeg -f concat -safe 0 -i clips-list.txt -c copy semilla-animated.mp4
```

### Opción C — Híbrida (recomendada)

Actos I, III y VI como clips animados (impacto emocional) + actos II, IV, V como imágenes estáticas con interpolación. Balancea costo de Replicate y fluidez narrativa.
